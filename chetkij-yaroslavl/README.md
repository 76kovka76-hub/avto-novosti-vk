# Чёткий Ярославль

Отдельный новостной бот для группы ВКонтакте https://vk.ru/club243223029 (ID 243223029).

## Как работает
- GitHub Actions проверяет новости каждые 5 минут; в расписании 30 слотов по 48 минут по московскому времени.
- Берёт RSS-кандидатов по городу Ярославлю; источники необходимо проверять на доступность и допустимость получения материалов.
- Не публикует новости старше 36 часов; отсекает повторы ссылок и похожих заголовков.
- ИИ отказывает, если новость не подтверждает событие в самом Ярославле, повторяется или недостаточно фактов.
- Формат: одно короткое предложение в дружеском пацанском стиле + три тематических и ранее неиспользованных хэштега со словом «Ярославль».
- Сохраняет историю в `chetkij-yaroslavl/history.json` без обрезания. Критичные события требуют аккуратного тона.
- **30 — верхний предел**, а не гарантия: при нехватке проверенных новостей пропускает слот.

## Перед запуском
1. Проверьте источники в `bot.py` и наличие нужных материалов, точность и допустимость RSS.
2. В Settings → Secrets and variables → Actions → Repository secrets добавьте:
   - `YAROSLAVL_VK_TOKEN` — токен ВК с разрешением на публикацию в группе 243223029.
   - `YAROSLAVL_OPENAI_KEY` — API-ключ OpenAI (никогда не вставлять в код).
3. Изначально в workflow установлено `DRY_RUN: "true"`. Проверьте тестовые логи, убедитесь, что посты корректны.
4. Для реального автопостинга после теста измените `DRY_RUN` на `"false"` **отдельным изменением**, которое осознанно проверите.
5. Workflow по cron начинает работать на default branch после слияния PR. Запуск из feature-ветки возможен через workflow_dispatch при доступности.
6. GitHub Actions — не строгий таймер, возможны задержки или пропущенные запуски.
7. Проверьте разрешения для Actions: workflow должен иметь право записывать `history.json`, иначе защита повторов после перезапуска не сохранится.

## Важные ограничения
- Заголовок RSS и краткое описание не гарантируют достоверность. Прежде чем включать полностью автономный режим, желательно добавить сверку с официальными источниками и контроль рискованных тем.
- Сходство заголовков и проверка ИИ уменьшают вероятность повторов, но не гарантируют стопроцентного отсутствия семантических дублей.
- Никогда не используйте чужие фотографии без прав на публикацию. Здесь публикуется только текст.
- Старый бот `main.py` и его workflow никак не меняются.
