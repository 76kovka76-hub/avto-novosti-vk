# Автоновости VK

Автоматическая публикация коротких автомобильных новостей в сообщество VK.

## Как работает
- 20 временных слотов в сутки по московскому времени: 00:00, 01:12, 02:24 ... 22:48.
- GitHub Actions проверяет расписание каждые 5 минут; публикация выполняется только для наступившего слота.
- Новости загружаются из RSS Motor.ru и «За рулём».
- Публикуются только уникальные новости не старше 72 часов.
- Каждый пост состоит из одного предложения и трёх хэштегов.
- История ссылок и использованных хэштегов сохраняется в `post_history.json`, чтобы избегать повторов.

## Секреты GitHub
В Settings → Secrets and variables → Actions добавьте:
- `VK_ACCESS_TOKEN` — токен VK с правом публикации на стене сообщества.
- `VK_GROUP_ID` — числовой ID сообщества: `242840147`.

После добавления секретов запустите workflow через Actions → Auto news VK publisher → Run workflow. Ручной запуск проверит, наступил ли очередной слот публикации.

## Важно
Если в RSS-лентах нет свежей уникальной новости, скрипт ничего не выдумывает и повторяет проверку через 5 минут. GitHub Actions может запускаться с задержкой, поэтому публикация не гарантируется ровно в минуту слота.
